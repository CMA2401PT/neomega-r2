操作帮助

        
      

      

        
预览与时间

        

          

            体素渲染器
          

          

            用纯色方块简化模型，省去贴图和光影，资源占用最低。适合快速浏览大范围地形。
          

          

            基础渲染器
          

          
显示完整方块模型和贴图，方便检查建筑的形状与用材。

          

            光影渲染器
          

          
加入阴影、远景雾和水面反射，适合观察光照或取景。

          

            隐藏
            HUD
          

          

            收起工具栏和读数，让出观察空间。右上角只留一只划掉的眼睛，点它即可恢复。
          

          

            静止时累积
          

          

            停下相机后持续采样，让画面逐渐清晰。开启时会暂停时间流逝。
          

          

            时间流逝
          

          

            让太阳随时间移动，观察昼夜光照。拖动右侧滑条可直接选择时刻。
          

        

        
地图与画面

        

          

            全屏地图
          

          

            从上方查看周围地形。点选方块后可跳转到该处，再点地图图标或按
            Esc 返回。
          

          

            导出当前画面
          

          

            用当前预览渲染器重绘视图，采样完成后自动保存
            PNG。适合保留当前画面风格。
          

          

            拍照
          

          

            用累积渲染器逐步细化照片。满意时再按一次相机保存 PNG，按
            Esc 可放弃。
          

          

            设置
          

          

            按相机、光照、画面、输出、调试和参数组分页。面板贴在屏幕一侧（竖屏时在底部），打开时收起底栏，可以一边拖动视角一边调整。
          

        

        
移动、坐标与地图缩放

        

          

            水平移动
          

          

            触屏方向键按相机朝向前进、后退或左右平移。键盘使用
            WASD。
          

          

            升降
          

          

            触屏升降键沿高度方向移动。键盘用空格上升、Shift 下降。
          

          

            地图缩放
          

          
拖动地图底部的滑条，从局部地形缩放到大范围概览。

          

            跳转到坐标
          

          

            编辑底部的 X、Y、Z 后点箭头或按回车，直接飞到指定位置。
          

          

            操作帮助
          

          
打开这份图标说明。点右上角的关闭按钮或按 Esc 返回。

          
检查近景 SNBT

          
点击坐标右侧的手套，红色线框会标出近景中带 SNBT 的方块。点击这些方块或展示框可查看原文。再点一次手套即可退出检查。

          
渲染器信息

          
点击左上角帧率旁的芯片可查看视距、区域加载进度、显存用量和 GPU 耗时。

neOmega R2 是一个射线渲染器，并可以绘制大范围地形且对光影有一定支持。

          

            本项目未直接使用以下项目的代码，但许多关键数据来自它们：
            Amulet、
            GeyserMC
            和
            MC-Assets。 本项目已在 amuletmc.com 购买 Amulet

视距

          
          
          
近景启用特殊对象，远景覆盖完整静态模型。

          
画质

          
          
          
XS 和 S 是两个超轻量 2× 模型，提升有限。建议在渲染分辨率低于窗口实际像素数时开启。

          
          
          
远景雾只在光影渲染器中出现。

          
        

        

          
          
开启超分后可用。导出和拍照默认保存所选尺寸；勾选后 PNG 的宽高各翻倍。

          
导出当前画面

          
          
          
用当前预览渲染器重绘。超采样在每个像素内多次取样，平滑方块轮廓。4×4 采满 16 轮后自动保存。

          
拍照

          
          
          
用累积渲染器逐轮细化，4×4 需 16 轮才覆盖完整网格，高分辨率更耗显存。再按相机按钮保存 PNG，按 Esc 放弃。
