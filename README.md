# neomega-r2：统一的格子射线渲染

R2 用同一条射线管线绘制完整方块、复杂静态方块和实验中的活动部件。射线先穿过空间格子，再检查格内登记的对象：完整立方体直接确定命中面，复杂模型检查预生成表面，活动部件先变换射线再求交。所有命中共用由近到远的排序与透明合成。

目标是在实际存档中保持可用性能，同时统一近景和远景的绘制方法。当前支持只读 Java 存档的固定观察窗口，以及独立的静态、动态实验场景。观察窗口覆盖 1536×1536×512 方块；近景按半径 8 区块的圆形水平范围、上下各 9 个 section 选择完整静态模型。section 是 16×16×16 的存储区域。远景使用预生成的简化外观，完整立方体仍保留面贴图。

## 区块为什么只需要索引

模型在生成资源时解析一次。每个方块状态得到共享模型编号，完整立方体引用六面贴图描述，复杂模型引用三角面列表。重复三角面只保存一次。越界模型按整数格边界裁切，裁切时插值 UV；只分割原表面，不给切口封口。每个片段已经处于目标格的局部坐标，因此绘制时无需搜索相邻格子的模型。

Java 存档本来就把一个 section 保存为调色板和压缩索引。调色板列出出现过的方块状态，压缩索引决定每格使用哪一项。`world.go` 在打开存档时建立共享状态映射，读取区域时只转换调色板条目，同时发布近景和远景模型编号，压缩索引原样传输。Go 仍需读取、解压和解析存档，但区域请求不生成模型、剔面或合并网格。

浏览器后台线程根据观察中心选择模型编号，把预裁片登记到目标格，并建立用于跳过空气、均匀立方体的空间层次。GPU 保留 section 的压缩索引，只有射线进入非均匀区域时才读取格子编号。整个远景窗口没有逐格分配稠密数组。单值 section 可以直接在粗层次合并，不需要格内跳跃表。

```text
生成资源：模型 → 按格裁切 → 共享表面、贴图、片段和远景外观
读取存档：调色板状态 → 查表；压缩格子索引 → 直接传输
后台线程：选取近远景外观 → 登记裁片 → 建立跳跃层次
逐像素绘制：进入候选格 → 求交 → 采样 → 按命中顺序合成
```

玻璃、水采用同组介质的边界规则，内部接缝不贡献颜色，不随穿过厚度持续加深。水目前仍为完整高度的立方体。存档中的 `waterlogged=false` 正常映射到方块本体；`waterlogged=true` 目前也只显示本体，附加水层尚未接入。

## 特殊对象怎样进入同一条射线

独立特殊场景包含附魔台、活动书页、玻璃、石英遮挡物，以及使用私有贴图的旗面。附魔书复用原 viewer 的部件布局和动画参数；七个盒体的形状只创建一次，每帧更新实例变换。旗面使用固定测试图案，图案中留有透明孔，便于验证穿透。

活动对象登记到整个动画可能经过的格子中。射线进入当前格后，把射线变换到对应部件的局部坐标求交，并把结果交回公共命中排序。动画不需要每帧重切三角面，也不要求相邻射线命中相同对象。这个场景验证的是实例变换、私有贴图、遮挡和透明裁切；还没有接入真实存档的旗帜 NBT、告示牌排版、粒子和任意实体动画。

## 代码和资源从哪里来

`catalog.go` 定义共享模型表，`scene.go` 构造独立验证场景，`world.go` 只读存档并提供压缩调色板。`cmd/r2` 提供 HTTP 服务。`web/world-worker.js` 建立存档窗口，`web/ray.frag` 负责空间遍历、表面求交与合成；`web/special.js` 和 `web/special.frag` 提供活动部件实验。页面没有区域网格，屏幕三角形只负责发射射线。

`cmd/build-models` 读取复制的输入资源，生成共享表。静态模型、原图集和独立 mip 来自 viewer-core `8afee71`；附魔书贴图与部件布局也从该版本复制。`internal/sourcegeometry` 仅供生成命令解码固定输入。R2 不导入 viewer-core 或 viewer；存档读取依赖 `celler`，状态目录依赖 `neomega-blocks`。许可证见 [LICENSE](LICENSE) 和 [资源说明](sourceassets/THIRD_PARTY_NOTICES.txt)。

执行 `go generate ./neomega-r2` 生成的目录包含 2768 个快速立方体状态、19562 个通用静态状态和 26349 个共享模型/片段（包含远景简化外观）。134382 个唯一三角面由 459930 个面索引引用；843 个源模型需要跨格裁切。源表中另有 47 个状态没有表面，详见 `assets/catalog.json`，其中也包含本来就是空形状的墙状态。

## 怎样运行和比较画质

从工作区根目录启动只读存档服务：

```sh
go run ./neomega-r2/cmd/r2 \
  -listen 127.0.0.1:2412 \
  -world '/Users/dai/Downloads/新天堂'
```

打开 <http://127.0.0.1:2412>。不指定 `-world` 时默认打开独立静态场景；特殊对象场景地址为 <http://127.0.0.1:2412/?scene=special>。拖动转向，WASD 移动，Q/E 升降。存档初始位置为本实验的固定坐标 `(1280,271,1280)`，不是通用出生点读取器。

页面显示实际画布像素尺寸。“屏幕原生”使用设备像素比，“1×”使用 CSS 尺寸。每像素可以选 1、2、4 条射线，多条射线在线性颜色空间平均，主要减轻几何边缘锯齿。测试默认不降分辨率，也不使用时间累积或重建。

存档窗口按加载时的观察中心选取近远景模型，移动不会自动更新窗口。点击“以当前位置加载存档窗口”可重建范围；重建期间暂停绘制。数据在整个窗口准备完毕后一次上传。连续流式调度、跨窗口增量发布和回收仍需实现，因此当前移动测试只覆盖已加载窗口内的运动。

开发时可直接读取网页目录：

```sh
go run ./neomega-r2/cmd/r2 -listen 127.0.0.1:2413 \
  -web ./neomega-r2/web -world '/Users/dai/Downloads/新天堂'
```

构建和验证命令：

```sh
go generate ./neomega-r2
./check.sh neomega-r2
node neomega-r2/experiment/check.cjs
node neomega-r2/experiment/special.cjs
node neomega-r2/experiment/world.cjs
```

测量条件、旧版对照、原生分辨率截图和多采样代价见 [实验说明](experiment/README.md)。复杂静态表面目前仍使用原图首帧采样；其缩小过滤与动画还需要单独完善。
